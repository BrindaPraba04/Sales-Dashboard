Sales Dashboard (Power BI)

Project Overview
Developed an interactive sales dashboard to analyze revenue, regional performance, and product trends. Performed data cleaning and transformation to ensure accurate reporting and created visualizations to identify key business insights and support decision-making.

Objectives
* Monitor overall sales performance
* Identify top-performing products and regions
* Analyze revenue trends over time
* Detect underperforming areas

Tools Used
* Power BI
* Excel

Key Features
* KPI cards for revenue, profit, and sales growth
* Region-wise and product-wise analysis
* Monthly revenue trend visualization
* Interactive filters for dynamic analysis
